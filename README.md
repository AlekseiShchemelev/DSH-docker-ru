**Контейнерный набор и визуальная консоль Web Admin, готовые к использованию из коробки**, созданные специально для официального DeepSeek Harness. На современной основе **Debian 13 (Trixie) & Node 24 (glibc 2.41)** одной командой решаются ограничения петлевой сети официальной версии, развязывается глобальный `NODE_ENV` с возвратом чистой среды разработки, добавляется лёгкая аутентификация доступа и статический версионированный рабочий стол noVNC; а с помощью **новой трёхколоночной панели ядра Web Admin и системы безопасной миграции** реализованы онлайн-горячее переключение версий ядра DSH, полностью автоматическое резервное копирование снимками, управление магазином плагинов сообщества и визуальное обслуживание.

Если коротко: **современная основа Debian Trixie, мощная консоль Admin в комплекте, развертывание Docker одной командой, всё готово из коробки.**

## 🚀 Развертывание Docker одной командой

### 1. Быстрый запуск одной строкой (рекомендуется)

#### Вариант А: запуск чистой базовой версии (по умолчанию `:latest`)
```bash
docker run -d \
  --name deepseek-harness \
  --restart unless-stopped \
  -p 3080:3080 \
  -e AUTH_TOKEN=admin \
  -v $(pwd)/data/dsh:/root/.dsh \
  -v $(pwd)/workspace:/workspace \
  -v $(pwd)/data/snapshots:/root/.dsh-snapshots \
  -v $(pwd)/data/browser:/root/.config/chromium \
  ghcr.io/misaka-link/deepseek-harness-docker:latest
```
*(Если нужна точная привязка, тег можно указать как встроенную версию DSH `:0.2.1-alpha.2` или версию проекта `:0.2.3`)*

#### Вариант Б: запуск версии с предустановленным магазином плагинов (по умолчанию `:latest-market`, из коробки включает магазин плагинов dshmarket)
```bash
docker run -d \
  --name deepseek-harness-market \
  --restart unless-stopped \
  -p 3080:3080 \
  -e AUTH_TOKEN=admin \
  -v $(pwd)/data/dsh:/root/.dsh \
  -v $(pwd)/workspace:/workspace \
  -v $(pwd)/data/snapshots:/root/.dsh-snapshots \
  -v $(pwd)/data/browser:/root/.config/chromium \
  ghcr.io/misaka-link/deepseek-harness-docker:latest-market
```
*(Если нужна точная привязка, тег можно указать как встроенную версию DSH `:0.2.1-alpha.2-market` или версию проекта `:0.2.3-market`)*

После запуска откройте:
- **Панель управления Web Admin**: `http://<IP-сервера>:3080/admin/` ⭐
- **Интерактивная рабочая область DSH Web**: `http://<IP-сервера>:3080/`
- **Рабочий стол Chromium в контейнере**: `http://<IP-сервера>:3080/vnc/`
- **Код доступа по умолчанию**: `admin` (после входа его можно в любой момент изменить в админ-панели)

### 2. Оркестрация контейнеров Docker (docker-compose)

#### Чистая базовая версия (`docker-compose.yml`):
```yaml
services:
  deepseek-harness:
    image: ghcr.io/misaka-link/deepseek-harness-docker:latest
    container_name: deepseek-harness
    restart: unless-stopped
    ports:
      - "3080:3080"
    environment:
      # Код доступа (для входа в Web, админ-панель и VNC-рабочий стол; если оставить пустым — вход без пароля)
      - AUTH_TOKEN=admin
      - PROXY_PORT=3080
    volumes:
      - ./data/dsh:/root/.dsh
      - ./workspace:/workspace
      - ./data/snapshots:/root/.dsh-snapshots
      - ./data/browser:/root/.config/chromium
```

#### Версия с предустановленным магазином плагинов (`docker-compose.market.yml`):
```yaml
services:
  deepseek-harness:
    image: ghcr.io/misaka-link/deepseek-harness-docker:latest-market
    container_name: deepseek-harness-market
    restart: unless-stopped
    ports:
      - "3080:3080"
    environment:
      - AUTH_TOKEN=admin
      - PROXY_PORT=3080
    volumes:
      - ./data/dsh:/root/.dsh
      - ./workspace:/workspace
      - ./data/snapshots:/root/.dsh-snapshots
      - ./data/browser:/root/.config/chromium
```

Запуск одной командой:
```bash
# Запуск чистой базовой версии
docker compose up -d

# Или запуск версии с предустановленным магазином плагинов
docker compose -f docker-compose.market.yml up -d
```

## ⚙️ Основные переменные окружения

| Переменная | Значение по умолчанию | Описание |
|---|---|---|
| `AUTH_TOKEN` | `admin` | Код доступа (если оставить пустым — пароль не задаётся, разрешён весь доступ) |
| `PROXY_PORT` | `3080` | Единый внешний порт (общий для Web, Admin и VNC) |
| `ADMIN_PATH` | `/admin` | Путь доступа к панели управления Web Admin |
| `VNC_PATH` | `/vnc` | Путь доступа к графическому рабочему столу noVNC |
| `DSH_WORKSPACE` | `/workspace` | Каталог рабочей области DSH AI по умолчанию |
| `DSH_DESKTOP_ENABLED` | `1` | Включён ли встроенный графический рабочий стол Chromium (1: вкл., 0: выкл.) |
| `DSH_DESKTOP_WIDTH` | `1920` | Ширина рабочего стола в пикселях (можно динамически менять в админ-панели) |
| `DSH_DESKTOP_HEIGHT` | `1080` | Высота рабочего стола в пикселях (можно динамически менять в админ-панели) |
| `HTTP_PROXY` / `HTTPS_PROXY` | нет | Исходящий сетевой прокси (полностью поддерживается нативно начиная с DSH 0.1.5-rc.1) |
| `NO_PROXY` | `localhost,127.0.0.1` | Список адресов, идущих в обход прокси |
